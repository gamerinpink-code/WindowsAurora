# WindowsAurora

Real-time GPU-accelerated Windows system audio visualizer built with **.NET 8 WPF**, **SkiaSharp**, and **NAudio** WASAPI loopback capture.

## Visualizer Modes
1. **Northern Lights (Aurora Ribbons)** — Multi-layered glowing silk curtains with exponential bass/mid/treble modulation.
2. **Radial Cyber-Halo** — Dual mirrored radial spectrum with dynamic hue shifting and core bloom.
3. **Hyperdrive Starfield** — 3D depth-projected particle warp tunnel reactive to bass & mid transients.
4. **Liquid Silk Oscilloscope** — Chromatic RGB stereo waveform strands.
5. **Neon Spectrum + Peak Hold** — Logarithmic frequency bars with mirrored floor reflection and peak caps.

## Controls & Hotkeys
- **`F11` / Double-Click**: Toggle true borderless fullscreen (auto-hides HUD & cursor after 2.5s idle)
- **`Esc`**: Exit fullscreen
- **`1`–`5` or `Left` / `Right` Arrows**: Switch visualizer modes
